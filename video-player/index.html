News Player Features

Accessibility

  • Keyboard Navigation Support
  • Screen Reader Compatibility
  • Customizable Font Sizes
  • High Contrast Mode

Advanced Features

  • DRM Support (Widevine, PlayReady)
  • HLS Streaming Support
  • IMA3 Pre/Post Roll Ad Support
  • Picture-in-Picture (PiP) Mode
  • Fullscreen Support

Player Controls

  • Play/Pause
  • Volume Control
  • Seek Bar with Thumbnails
  • Playback Speed Control (0.5x, 1x, 2x)
  • Customizable Controls Layout and Theme

Additional Features

  • Multiple Aspect Ratios (16:9, 9:16)
  • Custom Video Sources
  • Live Stream Support with 30s Buffer
